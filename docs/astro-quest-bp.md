# Stardy · 天文 + 知识科普产品矩阵 — Business Plan

> 写于 2026-08-25 · 项目：`astro-quest/`（Eazo 平台 Next.js 应用）
> 用户决策：**"先天文 → 再观鸟 → 再所有知识类可套用。先免费。不做班级。"**
> 配套：`astro-quest-brainstorm.md`（行动清单） · `astro-quest-template-architecture.md`（模板架构）

---

## 0. 一句话定义

**Stardy 不是天文 App，是「Duolingo 化知识科普产品的可复用模板」。天文（星旅）是第一条线，下一条线是观鸟（林间），之后是蘑菇 / 植物 / 古典乐 / ...。**

天文子品牌：**Stardy · 星旅 · 天文闯关**
观鸟子品牌（示意）：**Stardy · 林间**

> 单条线估值故事：「中国版天文 Duolingo」· ¥2-3 亿
> **模板估值故事：「Duolingo for Knowledge · 跨主题可复用」**· ¥20-50 亿

### 1.1 已经搭好的脚手架
| 层 | 已就位 |
|---|---|
| 平台 | Eazo App 容器（`@eazo/sdk` v0.22.8，auth/device/ai/storage/memory/notifications） |
| 框架 | Next.js 16 App Router + React 19 + Bun |
| 样式 | Tailwind v4 + shadcn 主题层 + 自研 `.sk-*` 设计 token（星夜深色 / 明亮） |
| 数据 | Drizzle ORM + PostgreSQL（已建 `users` 表 + 查询封装） |
| 国际化 | i18next + react-i18next，zh-CN / en-US 全词条覆盖 |
| 动效 | framer-motion |
| AI | `appAi` 客户端（Creator 代理 / BYOK 双模） + `appAIRequest` 浏览器封装 |
| 通知 | Vercel Cron + Eazo Notification API + `/api/notifications/cron/daily-digest` 定时下发 |
| MCP | `/api/mcp/route.ts` + `buildMcpServer(userId)` 已留接口，等加工具 |
| 状态管理 | `game-store`（关卡进度/经验/连胜/徽章）+ `theme-store` + `onboarding-store`（localStorage 持久化） |
| 设计系统 | 完整 token + 双主题 + 块状 3D 按钮语言 + 连击/连胜反馈文案 + speech-bubble 答题面板 + bottom feedback sheet + star-path 弯曲星图 |

### 1.2 已经做出来的体验
- 启动 Splash + 4 步 Onboarding（welcome / 选目标 / 选每日强度 / ready）
- 4 个主 tab：学习 / 每日一题 / 排行榜 / 账户
- 16 节关卡（3 章）：月相、北斗、猎户、行星天空、星等 → 太阳系 / 火星 / 土星 / 潮汐 / 日食 / 流星雨 / 彗星 → 极光 / 星系 / 黑洞 / 大爆炸
- 每关 = 2 张 teach card 图文讲解 + 3–4 道多邻国式选择/图片题 + 反馈弹窗 + 3 星结算页
- 每日一题：1 题、+15 XP
- 排行榜：白银联赛 + 8 个固定昵称假数据
- 账户：头像、连胜/XP/进度、主题/语言切换、8 枚徽章（4 已解锁、4 锁定）
- 平台封面预览：`/eazo-cover-preview` 自动循环播放一节课精华（问 → 答 → 升级 → 重复）

### 1.3 已知缺口
- 内容只有 16 关，远少于你写的「110–120 微节」目标
- 题型只有「单选 / 图片（emoji）单选」，没有真·拖拽、连线、配对、配音朗读
- 关卡是单线 S 曲线，没有真正的「树状知识图谱」（节点可以跳、可以选支线）
- 没有错题本 / 复习算法（FSRS / SM-2）/ 间隔重复
- 没有 streak freeze、XP 等级经验曲线、赛季奖励
- 没有真实的排行榜后端（当前是 module-local fake）
- 没有用户进度持久化到数据库（`users` 表只存了 id/email/name/avatar）
- 没有视频、没有真实星图渲染、没有「今晚看什么」模块
- AI 接好了但**还没有任何 AI 功能被调用**（错题讲解、自适应推荐、AI 出题）
- **主题抽象没做完**：内容 / 主题色 / 品牌资产 / i18n 词条全硬编码，没法直接复制到第二个主题
- 没有付费墙（用户决策先免费）

### 1.4 已有的"可复用底子"
虽然有以上缺口，但当前代码里其实已经做到了 60% 的"主题无关"：
- ✅ 内容 schema（`lib/astro/types.ts`）：Lesson/Question/Choice/TeachCard 完全通用
- ✅ UI 组件：StarPath / QuizCard / FeedbackSheet / LessonRunner / AppShell 通用
- ✅ 游戏机制：game-store 完全通用
- ✅ 设计 token：`.sk-*` 变量化
- ✅ Onboarding 流程：4 步通用结构，只换文案

剩下 40% 是把"主题包数据 + 主题色 + 品牌资产 + 主题专属模块"四样东西从硬编码里抽出来。详见 `template-architecture.md`。

## 2. 用户与场景

### 2.1 核心用户分层（用户决策后收敛）
| 层级 | 占比假设 | 真实诉求 | 价值锚点 |
|---|---|---|---|
| 🌃 城市白领（22–35 岁） | 50% | 「下班 5 分钟了解点星空/鸟类」 | 睡前仪式感 + 通勤 + 每日打卡 |
| 🧒 好奇心少年（13–22 岁） | 30% | 「我也能像 KOL 一样聊这个领域」 | 段子 + 视觉震撼 + 排名 |
| 🎓 爱好者（25–45 岁） | 20% | 「系统补某个领域的小知识」 | 进阶路径 + 真题 + 深度题解 |

> 砍掉了原方案里的「鸡娃家长」「中学老师」两条线（用户原话："没有班级要学天文"）。后续所有产品决策围绕这 3 层。

### 2.2 三种典型场景
1. **睡前 5 分钟**（最大场景）：躺在阳台看星空/挂望远镜看鸟，打开 App 学 1–2 节
2. **通勤地铁**：刷每日一题 + 看排行榜；地铁出来 1 节小课
3. **周末深度**：完成 1 个章节 → 解锁章节徽章 → 触发"换主题尝鲜"

### 2.3 主题切换场景（新增长场景）
- 学完天文第 1 章 → App 提示"想试试观鸟吗？" → 进入第二个主题
- 这是**模板价值变现的核心入口**

## 3. 市场与赛道

### 3.1 三大母赛道
| 母赛道 | 全球规模 | 中国规模 | 关键玩家 |
|---|---|---|---|
| 语言学习 App（Duolingo 范式） | $20B+（2025） | ~¥10B | Duolingo、Babbel；国内多邻国 |
| STEAM / 科普教育 | $400B+（全球 K-12） | ~¥300B | Khan Academy、少年得到、作业帮 |
| 天文 / 观星工具 | $1.2B | ~¥3亿 | Stellarium、Solar Walk、Star Walk |
| **观鸟 / 自然观察** | **$5B** | **~¥10亿** | **Merlin、eBird、懂鸟** |

### 3.2 没人做的事
把 **Duolingo 范式** + **可汗学院深度** + **天文/自然内容**三者叠加：

> **「Duolingo 模式 × 知识科普」是一片公开市场的真空白。**

证据：
- Duolingo 自己扩到 Math/Music/English 都是单 App 内多主题，没有"可被外部复用"的模板
- Khan Academy 是 K-12 全科，没法给一个 25 岁城市白领用
- 国内 OI 类天文 App 仅停留在「星座查询 + 每日一图」
- 国内观鸟 App（懂鸟）是图鉴工具，不是学习路径

### 3.3 时机窗口
- 2024–2026 中国 Space / Nature 主题大爆发
- AIGC 把内容生产门槛打掉 10 倍
- Duolingo 模式已被验证可迁移到数学（Math）、音乐（Music）、英语拼写
- 城市中产"轻学习 / 解压式学习"需求井喷
- **现在做是「Day 1」，晚 18 个月就会撞到字节/网易/腾讯教育**

## 5. 核心产品矩阵

把 Duolingo 的 9 大机制逐一映射：

| Duolingo 机制 | 我们的对应实现 | 状态 |
|---|---|---|
| 学习路径 S 曲线 | `StarPath` 弯曲星图 + 章节分隔 | ✅ 已有 |
| 连胜 / 火焰 | `stats.streak` + 头部火焰 pill | ✅ 已有 |
| XP / 等级 | `stats.xp` + 结算页 + XP pill | ✅ 已有 |
| 3 星评分 | settle 屏 3 星显示 | ✅ 已有 |
| 错题解析 | feedback-sheet 解释文案 | ✅ 基础 |
| 每日一题 | `/daily` 路由 | ✅ 已有 |
| 排行榜 / 联赛 | `/leaderboard` 白银联赛 | ⚠️ 假数据 |
| 徽章墙 | 8 枚徽章 + 锁定状态 | ✅ 已有 |
| 商店 / 心数 | ❌ 暂无 | ❌ 缺失（暂不做） |

### 5.1 第一版必须新增的机制（按 ROI 排）
1. **内容扩到 50 关 + 5 阶段**（用户决策：完整路线）
2. **用户进度入库**（基础设施）
3. **真排行榜 + 周赛季**
4. **错题讲解接 AI**（已接好的 Eazo AI 该用了）
5. **主题 token 抽象 + 内容进 DB**（**模板化的第一步**）
6. **通用模块 vs 主题模块插槽**（**为复制到观鸟铺路**）
7. **FSRS 间隔重复**
8. **题型扩展：拖拽 / 连线 / 配对**

### 5.2 模板化扩展（第二版再做的 12 个机制）
1. 知识图谱（节点可跳 / 支线）
2. 「今晚看什么」（天文）/「今天哪里有鸟」（观鸟）主题专属模块
3. 赛季分级
4. 主题切换器 + 全局 XP/徽章共享
5. 视频 + 互动小动画
6. 收藏卡（星座 / 鸟种 / 蘑菇种）
7. 多人俱乐部（同主题 / 跨主题）
8. AR 寻星 / 寻鸟
9. 推送系统（按主题订阅）
10. 主题包 SaaS 授权（终极商业模式）
11. 多语言扩展（es/ja/ko/fr）
12. 自然博物馆 / 鸟类协会 IP 联名

## 6. 商业模式（用户决策后重写）

### 6.1 决策
- **首版（0–6 个月）：完全免费**
- **B2B 班级：不做**（用户原话："没有班级要学天文"）
- **未来变现：主题订阅 + 品牌联名 + 主题包授权**

### 6.2 三阶段路径
| 阶段 | 时间 | 收入模式 | 现金流 |
|---|---|---|---|
| **M0-M2（首 6 个月）** | 纯免费 + 品牌联名赞助 | 自然博物馆、天文台、鸟类协会、世界自然基金会冠名 | 0 |
| **M3-M5（6-12 个月）** | 单主题免费 + 多主题订阅 | 第 2/3/4 个主题订阅 ¥18/月 / ¥168/年 / ¥328 终身 | 中 |
| **M6+（12+ 月）** | 全主题包订阅 + 主题包授权 | "Stardy 全主题包" ¥698/年 + 出版社/景区授权费 | 高 |

### 6.3 关键假设
- 免费是为了积累用户、内容、品牌；订阅转化点设在"学完第一个主题第 1 章"
- 单主题订阅比 Duolingo 全 App 订阅门槛低 → 转化率可能更高
- 主题包授权是终极故事：把"Stardy 壳"卖给出版社和景区 → 类比 Notion 模板、Shopify 主题店

## 7. Growth Loop

```
[ 内容触达 ]
   ↓  SEO「今晚月相」「5 月观鸟攻略」
[ App 内首章引导 ]
   ↓  完成第 1 章 → 解锁"想试试观鸟/蘑菇吗？"
[ 主题切换 ]
   ↓  进入第二个主题
[ 主题订阅触发 ]
   ↓  单主题免费 → 多主题订阅
[ 排行榜 / 俱乐部 ]
   ↓  排名提升触发分享
[ 外溢到小红书 / B 站 ]
```

北极星指标：**DAU 中「连续 7 天打卡」占比 ≥ 20%**（Duolingo 同口径约 8%）

## 8. 内容生产策略

### 8.1 主题 × 教材 × AI × 专家的四元
- 第一主题（天文）：教材 × AI × 专家
- 第二主题起：去掉"教材"，换成"图鉴 + 顾问 + AI"
  - 观鸟：Merlin / eBird API + 鸟类学顾问 + AI 出题
  - 蘑菇：蘑菇图鉴 + 微生物学顾问 + AI 出题

### 8.2 生产流水线
1. 编辑从权威源拆 1 个微节 → 写 teach card 骨架（中文 80 字）
2. AI（`appAi`，deepseek-v3.1）扩写出英文版 + 3 道题草稿
3. 真人专家审核 5 分钟
4. 入库 → 端上做 A/B 题干措辞测试
5. 60 天后看「错题率 / 跳过率」自动衰减 / 替换

> 单节平均成本目标：**5 分钟人工 + 1 分钟 AI**，比传统 MOOC 编辑效率高 30 倍。

### 8.3 主题包生产估算
- 第一个主题（天文）：8 人周（已 60% 完成）
- 第二个主题（观鸟）：**≤ 2.5 人月**（模板复用的硬指标）
- 第三个主题起：≤ 1.5 人月

## 10. 关键风险与对冲

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| 内容生产跟不上 | 高 | 高 | AI 草稿 + 编辑审校流水线 |
| 留存 7 天后断崖 | 中 | 高 | 加「今晚看」「我的观察笔记」「主题切换」三个钩子 |
| 模板抽象过度，做"万能壳"变笨重 | 中 | 高 | 第二个主题 10 周上线为硬指标；做不到就改架构 |
| 第二个主题找不到合适的内容顾问 | 中 | 中 | 内容联盟 / KOL 合作众包；AI 草稿兜底 |
| 主题切换分散单主题专注度 | 中 | 中 | 全局 XP/徽章共享让切换有积累感；不让"切换"破坏心流 |
| AI 成本失控 | 中 | 中 | Eazo Creator 代理 + 缓存命中 |
| 监管（青少年模式） | 中 | 中 | 内建开关 + 单日时长上限 |
| 抄袭 / 大厂跟进 | 高 | 中 | 靠"内容深度 + 模板速度"先占品类 |
| 天文本身小众 | 中 | 中 | 模板扩到 N 个知识类，分散单品类风险 |
