## Concept chain（按 skill 的 concept-mapping.md）

```
观鸟 → 在自然中寻找被忽略的细节 → 探索 → Explorer
     → 远眺（隐喻：双眼放大以关注微小） → 举起双筒望远镜
     → 双筒望远镜（symbolic object，1 类别） → lake teal `#2F7C82` 主色
     → coral `#D76555` 在望远镜背带 / 围巾处做 accent
```

|---|---|

## 验收（按 skill 的 evaluation.md）

### 硬性失败（任一命中必须重做）

- ❌ 出现多于 1 个动作 / 多于 1 种象征物
- ❌ 写实解剖 / 细致手指 / 写实眼睛 / 皮肤纹理
- ❌ 密集三角网格 / 光泽 3D / 渐变 / 电影光
- ❌ 强调色出现在皮肤 / 头发 / 眼睛 / 解剖特征上
- ❌ 动漫 / 皮克斯 / 游戏角色 / 超级英雄 / 时尚模特风
- ❌ 可读文字 / logo / 徽章 / 旗帜 / 商标 / 水印 / 性格类型代号
- ❌ 背景不是暖米白（出现场景 / 风景）
- ❌ 角色意外裁切 / 高度 < 70% 画布

### 集合一致性（≥6/7 通过）

1. ☐ 约 4.5–5 个头高
2. ☐ 棱角分明大头 + 紧凑梯形躯干
3. ☐ 小眼睛 + 楔形鼻 + 短嘴 + 克制表情
4. ☐ 几块大平涂多边形面 + 无轮廓
5. ☐ 一个安静、可读的动作
6. ☐ 主色调克制 + 一处小强调色
7. ☐ 128px 缩略图剪影清晰

## 关键约束提醒

按 skill 的 SKILL.md："Variation rule — Keep the visual grammar fixed. Vary only the character identity, metaphor, action, symbolic object, outfit, accent color, and silhouette within the permitted system."

意思是：这套图以后做**林间主题的系列**时（比如"鸟类救助者" / "观鸟入门指南角色"），所有图都得**遵守同一套视觉语法**（同一个 explorer + 同一套配色逻辑 + 同一种鸟）——只有身份/动作/象征物变化。这样形成"集合感"。

> 这就是 skill 想要的：让一个品牌下的多张角色图视觉统一，**让用户看了就知道是同一系列**。
